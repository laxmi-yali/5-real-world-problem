# 4-real-world-problem

This repository contains five beginner-friendly Python projects developed to improve programming and problem-solving skills. These projects demonstrate real-world applications of Python concepts.

** Projects Included

1. Student Login System

Allows students to log in using username and password.

Validates login credentials.

Displays success or error messages.

2. Student Marks Management System

Accepts student details and subject marks.

Calculates total and average marks.

Displays the student's grade.

3. ATM Banking System

Checks account balance.

Deposits money.

Withdraws money.

Displays the remaining balance.

4. Library Management System

Adds new books.

Displays available books.

Searches for books.

Issues and returns books.
